# THE DYNASTY — Official Alliance Website

Website resmi aliansi **The Dynasty** untuk game **Narco Empire**.
Aliansi ini aktif di **Server 32** (`[ DYNA ] TheDynasty`) dan **Server 53** (`[ DYNA ] TheDynasty2`).

> **Built From Zero. Built Together.**
> One Dynasty. One Journey. One Goal.

---

## 1. Deskripsi Proyek

Website statis (HTML, CSS, JavaScript murni) tanpa backend, tanpa build tool, dan tanpa dependency eksternal.
Seluruh data aliansi dibaca dari folder `data/` dalam format JSON.

Fitur utama:

- Landing page cinematic dengan hero, parallax, dan animasi scroll reveal
- Halaman server (Server 32 & Server 53) dengan data nyata dari `data/servers.json`
- Halaman recruitment + requirements + ranks
- Panduan pindah server langkah demi langkah
- Gallery dengan lightbox
- News berbasis JSON
- Form feedback berbasis `mailto:` (tanpa backend, tanpa klaim palsu)
- PWA (manifest + service worker + offline fallback)
