GUIDE

Cara Pindah Server

Panduan lengkap untuk bergabung dengan The Dynasty di server pilihanmu.

Perhatian sebelum memulai

Pindah server = membuat akun dari awal dikarenakan Narco Empire tidak mendukung perpindahan akun utama ke server berbeda.

STEP BY STEP

Sembilan langkah pindah server

  1. 01

    Buka Profil

    Pencet profil / foto profil pada layar utama game.

  2. 02

    Masuk ke Pengaturan

    Lalu masuk ke menu pengaturan.

  3. 03

    Pilih Karakter

    Setelah di menu pengaturan, pencet karakter.

  4. 04

    Pilih Server

    Setelah itu akan ada pilihan server 1 s/d 53.

  5. 05

    Tentukan Tujuan

    Pilih server 32 / 53 tergantung pilihan Anda.

  6. 06

    Naikkan Level Bangunan Utama

    Ikuti instruksi dan naikkan level bangunan utama agar cepat membuka fitur aliansi.

  7. 07

    Cari Aliansi — Server 32

    Lalu cari aliansi [ DYNA ] TheDynasty untuk Server 32.

  8. 08

    Cari Aliansi — Server 53

    Untuk Server 53 cari [ DYNA ] TheDynasty 2.

  9. 09

    Join

    Lalu join. Setelah masuk, segera gabung ke Discord kami untuk koordinasi lebih lanjut.

Butuh bantuan?

Jika kamu mengalami kesulitan saat mengikuti langkah di atas, tanyakan langsung di Discord kami. Anggota lain akan membantu prosesmu.
